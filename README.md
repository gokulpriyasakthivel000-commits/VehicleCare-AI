# VehicleCare AI

A classroom mini project built with Python, Flask, and Random Forest for both bikes and cars.

## Features
- Manual vehicle details form
- Random Forest maintenance category estimate
- Simple service reminder
- Mileage and fuel-cost calculator
- Downloadable PDF report

## Important dataset limitation
`dataset.csv` is a synthetic educational dataset generated with simple rules. It is not real workshop data and does not validate real-world fault detection. The model's accuracy only measures how well it reproduces the synthetic labels. Never use this app as a substitute for the owner's manual, warning-light instructions, or a qualified mechanic.

## Run locally
1. Install Python 3.11 or 3.12 and VS Code.
2. Open this folder in VS Code.
3. Create a virtual environment:
   - Windows CMD: `py -3.12 -m venv .venv`
   - Activate: `.venv\Scripts\activate`
4. Install packages: `python -m pip install -r requirements.txt`
5. Train the model: `python train_model.py`
6. Start app: `python app.py`
7. Open `http://127.0.0.1:5000`.

## Deploy on Render
- Push this folder to a GitHub repository.
- In Render, create **New + > Web Service** and connect the repository.
- Build command: `pip install -r requirements.txt`
- Start command: `gunicorn app:app`
- Choose the Free instance if available in your account.
- Deploy and open the URL Render gives you.

The model file `model.pkl` is generated by `train_model.py`. Render build command can instead be set to `pip install -r requirements.txt && python train_model.py` so the model is built during deployment. The service's local filesystem is ephemeral; this app does not store user records.
